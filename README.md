# Yaad Billing System

Lovable Prompt

Create a responsive web-based billing system for a business named "Yaad Vibrator".

Business Details:

Business Name: Yaad Vibrator

Address: Thalakudi, Mangalpur, Jajpur, Odisha

Features Required

Create a clean, modern UI with the following fields:

Customer Details

 Customer Name (Required)

 Mobile Number (Optional)

Booking Details

 Booking Date (Auto-fill today's date but editable)

 Service Date (Date on which the customer needs the service)

 Pickup/From Location

 Destination/To Location

Payment Details

 Total Amount (₹)

 Advance Paid (₹)

 Balance Amount (Automatically calculate: Total Amount − Advance Paid)

Bill Details

 Automatically generate a unique Bill Number (e.g., YV-2026-0001)

 Show bill generation date and time

Generate Invoice

When the user clicks "Generate Bill", create a professional printable invoice containing:

Header

YAAD VIBRATOR

 Thalakudi, Mangalpur, Jajpur, Odisha

BOOKING RECEIPT

Invoice Details

 Bill Number

 Booking Date

 Service Date

Customer Information

 Customer Name

 Mobile Number

Journey Details

 From Location

 To Location

Payment Summary

 Total Amount

 Advance Paid

 Balance Amount

Footer

 "Thank you for choosing Yaad Vibrator."

 "Please carry this receipt during the service."

 Authorized Signature
